# Fatafati Frontend

This is the frontend application for the Fatafati project, built with [Next.js](https://nextjs.org/) and [React](https://react.dev/).

## Technologies Used
- Next.js
- React
- TypeScript
- Lucide React (Icons)
- Canvas Confetti
- Vitest & React Testing Library (for testing)

## Getting Started

First, install the dependencies from the root directory:
```bash
npm install
```

Then, run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the application running.

## Available Scripts

- `npm run dev`: Starts the development server on port 3000.
- `npm run build`: Builds the Next.js application for production.
- `npm run start`: Starts the production server on port 3000.
- `npm run lint`: Runs ESLint to check for code issues.
- `npm run test`: Runs tests using Vitest.
